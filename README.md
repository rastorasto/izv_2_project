# IZV — Project 2: Traffic-Accident Analysis

pandas + seaborn analysis of the Czech police open dataset of traffic
accidents (2023–2025 XLS exports).

- Loads XLS straight from ZIP archives (cp1250), cleans the data, parses dates
  and region codes
- Exploratory questions with plots: weekday, severity and regional breakdowns

## Run

```bash
pip install -r requirements.txt && python analysis.py
```

Assignment brief in `zadani.pdf`. IZV coursework at FIT VUT Brno.
